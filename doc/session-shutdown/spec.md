# 正常退出会话标记修复

日期：2026-11-14。用户确认问题是每次打开工程都提示上次未正常关闭。

## 原因与范围

文件夹工程打开时写入`.session.lock`，返回工程列表时清除；直接关闭桌面主窗口或从应用菜单退出未清除。修复由原生进程跟踪本进程成功写入的会话标记，在主窗口实际销毁或应用正常退出时清理；取消关闭、辅助导出窗口关闭、崩溃/强制结束不应冒充正常退出。

只清理本进程仍拥有的标记。相邻实例已替换的标记必须保留；同目录写入与清理需要跨进程串行。不得修改工程正文、历史、对话或只读保护，不将会话标记当作保存成功凭证。

桌面实查另发现当前工程页面文件缺失，触发只读保护及历史媒体错误。这与本次重复异常退出提示不同，不通过删除页面索引或放开写权限来消除提示。

## 验收

正常主窗口关闭、应用退出清理自己的标记；异常退出残留仍可检测；辅助窗口及取消关闭不清理；其它实例/外部替换、符号链接不被删除；重复清理幂等，退出后的迟到标记写入被拒绝。原生测试、前端回归、类型检查及构建留证。
