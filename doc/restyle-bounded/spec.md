# 大页面重塑输出上限修复

2026-10-27，用户截图：单页406秒、正文45121/推理62576字符、续写0、输出上限。只读工程确认TA主页48294字符，其中21793为CSS、254节点。

BR-01 24000字符以上页面不再要求回传整页。原生页按最多24节点一组返回class增减；导入页按最多12个已存在颜色/背景CSS变量一组返回语义Token绑定。所有操作在副本应用，完成全部分组及原门禁后才可确认。不能新增DOM、变更文本/资源/任意CSS。无可绑定变量时前置说明需选择性HTML统一，不盲目重写。
BR-02 大页补丁总请求输出预算32768，每组2048，最多16组。超限/错误/越界/取消全页不应用，不拼接部分JSON。保留原head/stylesheet/资源和节点。已有导入源CSS变量可映射为项目命名空间Token；源CSS文本不计作可见业务文案漂移。原小页流程保持。
BR-03 进度分开显示样式补丁组数、请求数与真正HTML续写，不把分组当续写。估计调用数包含分组，试跑确认与History/档案/文件/像素门禁不绕过。
BR-04 仅重塑任务、官方阿里端点且明确支持切换的Qwen混合模型发送enable_thinking:false，非支持模型/其它端点不发送新字段，不改用户Provider设置。core和AIService两条序列化链路一致。
BR-05 修复小页显式未闭合HTML围栏不能识别时的续写入口；仅输出上限、已有HTML片段、预算允许时继续，纯推理/无HTML不盲目续写。来源模型API依据阿里官方deep-thinking文档（2026-10-19更新），不是根据名称猜私有参数。
