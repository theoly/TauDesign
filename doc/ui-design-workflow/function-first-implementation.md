pageTaskCoverage.ts 按冻结计划和实际 HTML 重算信息/操作线索，React 覆盖卡片接入对话结果及候选验收记录。输入要求仅在输入控件及关联 label/可访问名称中定位；操作要求仅在按钮/链接等操作入口中定位；脚本、样式、template 及显式隐藏资料不算线索。源码超 500,000 字符或 10,000 个节点时提示无法检查。线索随 HTML 指纹变化而重算，不缓存为可采纳权限，不修改 HTML/Token 或加额外 AI 请求。

所有线索保持 semanticStatus=unverified，未定位项提示结合预览核对；状态只列对应场景，完成条件仍待核对。该报告不充当业务验收门禁，也不将词义相近但未匹配的文案断言为功能缺失；原安全/结构/资源/实际渲染门禁继续执行。
