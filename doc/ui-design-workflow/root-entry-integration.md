## 规则

- 在现有AI设置提供单一“自动参考设计规则（试用）”选项，默认关闭。属于应用AI偏好，保存在现有AI配置中，不写入项目主题或更改工程设备。旧配置缺字段/非法字段按关闭读取；更新Provider/绑定保留偏好。
- 根调用方按新任务捕获偏好，覆盖文字/参考图新建、明确元素、已确认局部/区块/整页修改、检查器、多页/多方案与单页/批量重塑。多页计划和重塑批次冻结初始选择，不在子请求读变化后的设置。进行中、续写及已采纳结果不因开关改变而重选或撤销。
- 问答/主题、功能/多页事实规划、HTML确定性导入及独立资源协议保持排除。局部任务从精确授权DOM内提取已知语义；没有可靠目标则回退，不因请求词扩大范围或加载整库。
- 修改分析使用analysis-json专用适配。只利用原Token CSS排版字符窗口，保留Schema/原页/来源/白名单、两次格式上限和4,096申请输出。返回分析合同/实际回执供UI与确认来源记录查看，旧无来源分析兼容。
- 格式重试的失败JSON请求保留failed原状态；仅在该分析入口后续实际格式重试通过Schema后，登记“由后续请求替代”的前向链接。取消、网络失败不重试/不替代；其它生成协议不允许借此绕过不完整回执。
- 规则控制不是质量保证声明；M5前保持默认关闭。选择、组装、core派发/完成及页面实际校验分开。
