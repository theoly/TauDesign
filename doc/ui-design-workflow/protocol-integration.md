## 本轮开发与验收

- [x] 声明各工作流可用的规则协议；HTML/有限JSON/区块JSON/重塑补丁分别适配。业务功能规划和页面拆分先做事实组织，不注入视觉偏好；问答、主题和三种确定性导入排除模型审美改写。
- [x] Token JSON窗口只移除编译输出中声明边界后的换行/缩进；引号、注释、所有变量值、白名单、HTML/来源资料和输出约束原样保留。用释放字符预算选择整条规则，全部最终消息不比原消息更长；空间不足原样回退。不把字符预算当真实Token计费。
- [x] 包含协议身份的可选规则快照绑定当前任务；旧无字段快照兼容。有限JSON不能借用片段协议包。功能规划完成后才冻结修改规则，避免计划加入后绑定漂移。每次实际派发、续写/分区/补丁共享原快照、原core/代理与父预算，失败/取消/缺注入不得交付。
- [x] 补齐区块/结构元素/补充局部及单页/批量重塑的内部可选接线与真实请求形状测试；不是默认开启。小页润色替换原craft窗口，大页样式补丁利用Token排版窗口，不混入整页HTML协议。
- [x] 执行PC/mobile HTML、有限JSON、区块片段、续写及重塑补丁预算/协议干跑并归档；继续冻结正式留出集，M5前不默认启用。全量测试→类型→构建及相关浏览器通过后才勾验收项。

## 明确的失效/失败边界

协议、任务/目标/来源/保护或冻结正文变化拒绝；单独目录增加无关规则不重选旧快照。语义建议仍advisory，规则回执不替代实际渲染、资源、结构与源安全。被排除入口不伪造“已注入”或模型请求。没有足够空白预算时不裁掉Token、源HTML或半条规则，不提高原调用次数/输出额。
