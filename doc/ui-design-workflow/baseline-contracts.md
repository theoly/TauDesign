## 已有预算默认值（仅记录，不扩大）

- boundedContinuation：默认累计申请输出上限 32,768，自动续写最多 2 次；续写每次最多 8,192。调用方可进一步收紧。不是所有 Provider 都支持这些额度，实际仍受模型与调用配置限制。
- sectionedGeneration：同页 2～6 区块，规划 4,096；区块单次最多 4,096，单区块续写预算最多 8,192；已有总账记录保留，后续父任务账本不能逐层重置。
- restylePatches：每组 2,048，最多 16 组；原生 24 节点/组、变量 12 项/组，不允许续写。
- restyleExecutor：90 秒无活动、10 分钟总时限上限；AIService 默认 15 分钟、无活动最多 90 秒。不同调用路径的时限尚未统一，不能宣称所有任务已经共享父时限。

## 内部请求回执试点（2026-10-29）

PipelineExecutor 的 contextualGuidance 仍是显式代码参数，用户界面没有默认启用。操作和范围来自已裁决的 TaskContract，组件特征由内部调用方提供，不从资料中的命令授予范围。新建/修改请求可携带 designGuidance；问答/主题及原导入流程不生成此包。

回执边界是现有 AIEngineCore.streamText 的语义输入调用：保存散列、实际出现的规则 ID、父任务/子请求身份及状态，不保存模型请求正文、认证信息或图片数据。dispatched 只表示已交该应用边界，不证明网络送达；completed 表示文字与相关元数据 Promise 均完成，不代表页面质量通过。

生成前 preflight 可检查未完成包；交付阶段要求每个已记录请求完成且包含所选规则。已取消请求不会被晚到成功覆盖。作用域、规则正文或快照结构改变被拒绝；未使用当前目录重新解释历史规则。原无包合同继续走原门禁，新回执不替代渲染/内容/资源检查。散列是非安全用途的变化身份，不提供签名或对抗本地恶意文件篡改的保证。

## 父预算试点与继承边界（2026-10-29）

以下为首次预算试点记录；普通入口接线的当前状态见文末更新。

TaskBudget 是调用方持有的内存对象，不写入工程。内部场景 Pipeline 默认给每次明确启动的任务创建一次 16 请求/32,768 申请输出 Token/15 分钟总额；子请求共享账本，调用方也可显式跨子流程传入同一实例。常规路径不会自动启用新限制。手动重新启动任务与后台自动续写不同，旧检查点不代表额外预算授权；本轮不实现跨重启恢复父账本。

额度区分累计申请与在途预留：开始前同时扣减全局申请额度并占用在途额度，结束时仅释放在途额度；请求失败或实际使用很少也不补回已申请总额。缺少 usage 时记录该请求的申请上限为未报告额度，不捏造精确输入 Token 或费用；core 返回的 usage 也可能是既有估计，因此只称已报告量。累计申请与已报告量分别呈现，不相加。

总时限用单调时钟，挂起正文/元数据也可被中断，失败主动终止请求。重塑和文案建议服务已有可选父账本接口；所有调用方、批次 UI、传输内部重试的实际计数仍待统一。当前计数边界是 AIEngineCore 应用级调用，不宣称已覆盖一个调用内部的所有物理网络重试。

失败草稿保留原始规则来源及已完成回执；本地补文案以原冻结选择复核上下文。输出记录将该来源明确归为 historicalGuidanceSource，当前任务不生成 designGuidance 请求记录。原页、模型或上下文变化仍拒绝修复；新回执不能靠历史来源解锁。原无规则来源的草稿继续兼容。

## 根调用方与结束语义（2026-10-29 更新）

| 根任务 | 创建与共享边界 | 当前限额 |
| --- | --- | --- |
| 普通对话生成 | sendMessage 创建，Pipeline 与一次新页修复共用，finally 关闭 | 4 调用、34,568 累计申请输出、15 分钟；分区为 14 调用，其余相同 |
| 结构化修改 | executeStructuredEdit 按已授权模式/目标数创建并关闭；纯本地不创建 | 元素 1×2,048；补充 1×1,800；区块每个 4,096，最多原模式允许的目标数 |
| 文案建议 | 用户明确触发一次建议时创建，finally 关闭 | 1×1,800、15 分钟 |
| 修改分析/多页规划 | 各自规划函数拥有，两次格式请求共用并在 finally 关闭 | 2×4,096、30 分钟总额、每次 15 分钟 |
| 重塑试跑/单页 | runOne 拥有并关闭，已有执行器 10 分钟总时限仍有效 | 小页最多 3 调用，大页最多 16 补丁调用；累计 32,768 |
| 确认批量重塑 | executeRestyleBatch 为待生成目标创建；已确认试跑结果直接复用 | 按各目标原有小页/补丁上限求和；每目标累计 32,768/10 分钟 |
| 多页/方案确认生成 | executeMultiPagePlan 按确认页数创建，页内生成与一次修复共用并关闭 | 每页 4 调用、34,568；批次累计按确认页数求和 |

以上是申请额度上限，不是单次模型输出能力或预计费用；底层模型设置继续生效。确认后的任务和先前分析/试跑是用户明确分开的操作，不在同一次后台循环中重新创建账本。显式提供外部父账本的服务不能代替其拥有者关闭。

close 后拒绝后续请求；若仍在途则中断。耗尽标记阻止后续申请；已经生成且通过门禁的最后结果不会因恰好用尽额度被丢弃。批量额度不足时保留剩余项与停止原因，不重复尝试所有未请求目标；原先已应用项保留 History 撤销能力。正常任务预算已接入这些入口，场景规则替换仍未默认启用。剩余根入口与底层物理重试计数不在此表冒充全覆盖。

## 元素 JSON 协议试点（2026-10-30）

executeStructuredEdit 增加内部可选 contextualGuidance，仅支持明确元素修改；通用组件建议窗口可以用完整规则替换，尺寸、nid、文案授权、手动保护及 JSON 输出合同保留，原总提示词长度不增长。目标语义不足时保留原指导并记录回退。窗口不够不能截断规则或丢弃授权。

generateObject 回执在既有 core 边界记录 Schema/消息指纹和可选 outputProtocol=json-object；只记录输入身份，不保存原文/图片/凭证，不重写 core 的 JSON 解析器或代理。对象解析/结束原因失败记 failed，取消不能由迟到成功改成 completed。完整输入回执仍不能替代局部操作、质量、资源及渲染门禁。旧无 outputProtocol 的回执继续可读，不补造历史协议。

仅组装的合法冻结包可进入 preflight，完成后必须重新校验实际调用；实际用户指令与冻结合同不同则发送前拒绝。调用使用原元素父预算（1×2,048），无续写或额外重试。默认关闭、纯本地修改、问答与保真导入均不伪造使用记录；区块/补充局部/其它入口仍待独立适配。本轮未修改界面默认开关，未完成 M5 前不默认启用。
