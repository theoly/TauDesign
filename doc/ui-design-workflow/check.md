## 拟定评估门槛

关键固定查询首选正确且范围违规为零；一般 P@1 ≥ 0.85、负例回退 ≥ 0.95 为首轮拟定目标。真实生成对照要求首轮通过率不下降、严重问题不增加、盲评采用有明确改善；输入 token 和耗时中位数增幅分别以 10%/15% 为首轮目标。

上述数字不是当前实测成绩，也不是统计显著性声明。先冻结样例和评分依据；若样本不足或未达标，保持可选模式，禁止通过更新基线、删困难样例、无限重试把结果标为通过。

评分分母、改写族拆分、至少 24 对/48 次生成、双人盲评及 `(胜 + 0.5 × 平局)/全部配对 ≥ 0.60` 的试点目标以[实施方案 §10](./implementation-plan.md#10-评估目标与验证边界)为准。人手/模型条件不足保留缺口，不将单人偏好或缺失 usage 估计包装成正式放行证据。
