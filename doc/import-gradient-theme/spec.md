# 渐变主题与已有页面风格提取

2026-10-26，用户已确认analysis.md推荐方案，入口同时置于设计系统侧栏和完整主题编辑器。在现有codex/property-panel分支继续，保留已提交基线8b151aa，不创建额外工作区。

## 规则
- BR-01 保留纯色颜色Token兼容，新增分明暗模式的page/primaryAction/decorativeSurface背景角色，支持纯色、线性/径向和多层渐变。所有表达式经结构化校验编译，不能包含URL、注入或未解析变量；不支持的表达式保留源页并说明。
- BR-02 两个入口均叫“从已有页面提取风格”，共用面板。选择来源页面后列出角色候选、来源选择器、可信度、当前/候选预览；按角色选择，默认不自动应用。支持主色、字体、圆角等现有可识别项的选择性合并。
- BR-03 页面根背景、主按钮与装饰分开；不能把照片遮罩、头像或弹窗遮罩自动当作全局page。模糊候选只能作为装饰候选展示。保留当前明暗模式，不猜另一模式。
  用户可显式将某个局部渐变指定为“页面背景”等目标角色；系统默认分类不自动提升，变更后仍须勾选并确认。
- BR-04 主题编辑器可修改背景角色/角度/色标，设计系统预览真实基座CSS。提取来源随主题保存。Pinned reference禁止修改，需转为项目副本。
- BR-05 确认后由History一次提交主题、来源及选定旧页同步；未选旧页冻结此前背景角色，后续新页继承项目主题。已导入页面保留原CSS，选择同步时仅增加明确背景覆盖，不替换其业务DOM。手动L4背景优先，不强行覆盖并给出提示。
- BR-06 HTML导入在空/已有工程均可提示检测到的背景，默认仅保留本页；选择更新时仅合并勾选项。导入和选定主题更新同一次History事务，原页面/配置变化后需重看预览。
- BR-07 新页Prompt包含背景角色与继承规则；画布/独立HTML/PNG共用编译，旧纯色主题不受影响。局部修改不擅自替换背景。
- BR-08 只读分析用户原工程，验证使用独立夹具或副本；不请求模型、不执行导入脚本。

## 边界
不自动统一所有旧页；不将不确定CSS猜成高可信Token；不改变设备档位、DOM节点或设计库引用编辑权限。
