# UI 设计规则与指导

2026-10-29。依据用户提供的 Refactoring UI v1.0.1，将可迁移的设计原则改写为 TauDesign 的生成指导与人工审阅清单。

## 范围与契约

- 新建页面从用户目标和核心内容出发，再组织操作、布局与装饰；问答和主题设置不注入页面工艺规则。
- 修改/润色遵守既有任务合同、节点、文案、手动保护与修改范围。通用美学不得触发额外区块、新状态或整页重写。
- 当前设计系统、主题渐变、设备和导航合同优先。规则只推荐 base.css 在两档位都存在的通用类，不增加硬编码颜色、尺寸或 Tailwind 产物。
- 指导覆盖视觉主次、分组间距、文字对齐、内容宽度、配色角色、状态冗余表达、层次阴影和媒体裁切。既有硬门禁保持原语义，主观美学作为生成指导及人工审阅项。
- 新建页面提示词维持既有小于 12000 字符的基准预算；通过去重腾出空间，不放宽预算测试。
- 不实施此前暂存的参考页面资源库，不收集页面，不将书籍正文或截图放入仓库，不自动修改用户工程。

书中的拉丁文行长与字距建议不直接套用到中文。使用项目字号梯度和设备档位；长段落自然换行，禁止压窄为逐字竖列。图片/渐变上的可读性需要按实际叠加效果审阅；单一纯色对比度不能代替视觉验证。本文不新增无障碍标准定义。
