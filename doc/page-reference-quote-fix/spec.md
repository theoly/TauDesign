# 页面设计规格的引用解析修复

## 背景与目标

2026-11-14 用户提供“页面2：AI决策对话页”的完整规格。输入含会话标题“AI 决策分析”、动画/按钮文案等普通引号内容，实际被判定为“未找到引用页面”，且错误提示带入多行说明。复现资料是页面需求，不是本轮要求生成页面。

## 范围与业务规则

- 引用解析必须按真实引号配对、支持中英文成对引号，不能将前一段文字的结束引号当作“参考/分析页面”的开始引号；不跨行抓取页名；真正引用缺少结束引号时提示补全，不静默忽略。
- Markdown/纯文本明确页面规格标题及功能/交互/结构段落之后的页面名、示例文案属于设计资料，不能仅因与旧页同名便绑定旧页。规格之前的明确页名指令、规格中的明确参考语句、@ID/页名、引用开关继续有效。
- 未指定目标的该类规格按现有规则新建；真实未知/同名引用仍阻断，真实修改仍走原页候选流程。不能以“忽略全部引用错误”绕过安全校验。
- 路由、上下文富化使用同一解析结果，不改用户文本、不增加模型请求，不自动覆盖任何已有页面。

## 数据流与兼容

`resolveScreenReferences` → `resolveGenerationTarget` / `resolveMentions` → 上下文与管道。仅修改纯文本引用解析和一致性判断，不修改DOM、工程格式、主题、媒体或History发布机制。

## 验收

完整用户原文、同名页面、正常引用、未知/歧义引用及聊天入口回归；之后运行全量测试、类型检查和构建。
