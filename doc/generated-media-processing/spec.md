# 生成媒体自动处理

用户复现：AI 决策助手主页的五轴雷达图返回内联 SVG，被外部媒体断言直接拒绝。需求文档是复现资料，不是本次要求生成的新页面。

模型代码接收与工程产物分层：允许受控生成阶段短暂持有静态 SVG；必须先检查完整性与活动内容，再复用 SVG 外置器固化主题样式、生成 SHA-256 独立文件，回填引用，最后运行原有全部页面门禁。不得放宽工程页面、会话或恢复前缀的外部媒体规则。data/base64、blob、不安全 SVG 仍拒绝。已有资源优先复用，精确图表不额外调用位图模型。

覆盖：对话主体、整页、分区、自动续写、失败草稿修复，以及多页批次与共享生成树。媒体文件提前准备但不提前修改页面或主题；新建时通过同一条 History 登记页面和资产；修改时在暂存候选前核验并经 History 登记独立素材。取消、来源变化或资源冲突必须阻断。不可删除未登记的哈希文件，避免误删其他窗口共享资源。继续/恢复可从最终引用重新核对独立文件，不将二进制保存进任务元数据。

非目标：放开任意活动 SVG、自动运行用户文档里的绘图工具指令、把页面 UI 截图当作图表、替无图片 Provider 伪造位图结果。既有 HTML/PNG 导出内联例外保持。
