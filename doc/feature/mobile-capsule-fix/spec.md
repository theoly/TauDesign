# 移动端导航胶囊外观修复

## 背景与目标
截图中右上角胶囊横向拉伸并与标题重叠。通用 span 标题规则的选择器优先级高于胶囊规则，覆盖了固定布局。

## 范围与业务规则
- 修复移动端基座 CSS，沿用现有头部结构与 86 × 32 尺寸变量。
- 标题规则不得匹配胶囊；标题仍在屏幕中轴，胶囊保持右侧独立双分区。
- 更多区与圆形区等宽，分隔线位于中间；图标居中。
- 已有符合头部类名契约的页面直接受益，不改工程 HTML 或历史。

## 数据流与非功能要求
继续由 getBaseCss 注入 iframe 和导出，PC 不受影响。通过真实 DOM 样式级联回归测试、白名单覆盖、全量测试、类型检查和构建验收。
