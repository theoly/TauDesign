# 页面保存与重开恢复修复

日期：2026-11-15。用户反馈重新打开工程只有会话历史、画布为空且显示只读。

## 证据与目标

实际星运工程索引的5个页面及部分资源已被移至legacy，根目录缺少screens。后续7次新页面生成仍记录为已创建，但新建入口只在内存addScreen后异步保存，未等待存盘成功；只读保护拦截保存后，界面与对话仍宣称创建完成。

修复：生成之前检查工程是否允许写入；新建页面、资源登记与History经现有原子发布管道成功后才报告创建；发布失败/来源变化不留假成功和内存孤页。缺页恢复界面必须清楚说明工程需要恢复，不能显示普通新建引导。

## 真实工程恢复

先备份当前索引、历史、对话及将要恢复的文件。对照索引从legacy找回缺失正文及资源，不覆盖现存文件；校验任务独立产物与会话来源，保留后续生成内容并核对可恢复范围。恢复不调用AI、不改业务文案，不将历史规划或未验收草稿伪装成已验收页面。修复后核对存盘、重开、渲染与资源可读性。

## 边界

不删原索引、归档或legacy，不放开只读保护，不将会话存在当作页面已存盘；保留现有设备、样式、资源和候选门禁，所有新页面的状态与历史提交仍走History管道。
