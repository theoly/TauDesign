# 候选按钮无响应修复

2026-10-26，用户截图的“采纳新版 / 两版都留 / 保留原版”。只读原工程候选确认：8项交付检查仅structure被阻断（新增10/丢失10），其它7项已通过。画布未直接展示该原因，禁用按钮却保持亮蓝；聊天有部分原因，画布没有一致反馈。

修复范围：画布显示当前阻断/等待原因、禁用外观与可访问说明；仅在唯一未通过项为结构检查且其它门禁全部通过时，允许用户显式勾选接受当前结构变化，再选择替换或保留两版。复用既有强制结构采纳管道，并为两版保留加入明确的交付模式；结构确认绑定完整候选渲染上下文，换候选、原页、Token/资料或设备后失效。源安全、静态质量、实体、资源、当前iframe检查不能被确认绕过。正常可采纳候选不需要额外确认，保留原版始终可以丢弃候选。

候选操作工具条隔离画布的平移/滚轮/空格事件；服务层仍在提交前重算门禁并给出失败原因。交付前后版本、文件读取、History和存档继续原管道，不写用户原工程作为排查动作。

不扩大结构分析器关键词、不自动放行7/8、不触发模型请求、不静默采纳用户的当前候选。验证先用独立夹具，再只读装载真实候选到隔离副本进行浏览器验证。
