# 长规格中的当前页面范围识别

日期：2026-11-14。用户提交StarFate完整全局规范和P08排盘资料录入规格，却进入多页面规划并提示一次最多8页，未调用模型。

## 原因与范围

`requiresMultiPagePlan`和`requestedPageCount`扫描整段原文，项目总交付28页、材料1/2页及上传页数预算都可能成为本轮生成数量。现有编号页面规格识别只支持“页面2：”，不支持P08标题。

## 规则

- 从明确编号标题及结构化展示/字段/操作/状态章节识别当前页面规格，支持普通、Markdown、转义Markdown及P编号。页面规格与项目总量、材料页数、跳转目的地、参考页面分开。
- 一个明确页面规格按单页设计；多个完整目标规格按实际规格数规划。明确要求本轮批量生成的独立指令继续优先，真正超限不能被忽略。没有明确规格时维持原有分类。
- 路由/数量/交付校验复用同一范围视图；只读分析视图不裁剪模型输入，不丢全局要求或关联说明。不新增模型请求。
- 保留明确引用、修改、元素和多方案流程的授权约束；普通规格标题不能误绑定同名旧页。
- 不提高8页限制、不自动生成项目全量页面，不修复独立的缺页或只读状态。

## 验收

完整用户提示、转义形式、项目总量与材料数量、参考附录、同名已有页、真正多页/超限及聊天入口回归。定向验证后执行全量测试、类型检查和构建。
